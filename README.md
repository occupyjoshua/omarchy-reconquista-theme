# Reconquista

A dark [Omarchy](https://omarchy.org) theme of crusader-era Christendom, centred on Baldwin IV, the leper king of Jerusalem (1161–1185).
Forged iron, bone, and tarnished gold, with wallpapers drawn from Byzantine mosaics, crusader-era
paintings, Gothic glass, and the arms of the Kingdom of Jerusalem.

## Install

```bash
omarchy theme install https://github.com/occupyjoshua/omarchy-reconquista-theme.git
```

## Palette

| | | |
|---|---|---|
| background `#121314` | foreground `#d8cfbd` | accent `#b8923a` |
| red `#c4554a` | green `#a39a5c` | yellow `#c9a14a` |
| blue `#8c8a82` | magenta `#b46d59` | cyan `#b3a68a` |

Gold is kept to the focused window border, selections, and highlights. Everything else
stays iron and bone. Terminal, editor, bar, and app themes are generated by Omarchy
from `colors.toml`. Icons: Yaru-wartybrown. The boot screen shows the Jerusalem cross.

## Wallpapers

1. *Battle of Montgisard*, Charles-Philippe Larivière (1842–44)
2. *Christ Pantocrator*, Deësis mosaic, Hagia Sophia (13th c.)
3. *Entry of the Crusaders into Constantinople*, Eugène Delacroix (1840)
4. Sallet helmet, Nuremberg (1480–85)
5. Votive candles
6. Sainte-Chapelle window with the castles of Castile
7. Sainte-Chapelle upper chapel
8. Christ Pantocrator, Cefalù Cathedral (1148)
9. The Jerusalem cross, arms of the Kingdom of Jerusalem

Sources and licences are in [CREDITS.md](CREDITS.md). `build.sh` re-fetches the originals
from Wikimedia Commons and rebuilds every wallpaper.
